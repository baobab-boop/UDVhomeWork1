Анкета дотера
10 вопросов по механике Dota 2 (плюс бонусный), а в конце анкета по количеству верных ответов определяет MMR.

1. Проверка компонентов
dotnet --list-sdks
dotnet workload list

2. Установка MAUI (если его нет)
  Через Visual Studio:
  1. Запустите Visual Studio Installer.
  2. У нужной версии Visual Studio нажмите «Изменить».
  3. На вкладке «Рабочие нагрузки» отметьте «Разработка .NET Multi-platform App UI» (.NET MAUI).
  4. Нажмите «Изменить» и дождитесь окончания установки
  
  Через командную строку:
  Откройте PowerShell от имени администратора и выполните:

dotnet workload install maui

3. Запуск в Visual Studio

  1. Запустите Visual Studio → «Открыть проект или решение».
  2. Выберите файл `Task02_Anketa\Task02_Anketa.csproj`.
  3. На панели инструментов в выпадающем списке рядом с зелёной кнопкой запуска выберите:
   - Framework  `net10.0-windows10.0.19041.0`;
   - цель запуска  Windows Machine.
  4. Запустите (f5)
  5. Первая сборка занимает 1–2 минуты, затем откроется окно «Анкета дотера».

   Запуск на Android в Visual Studio

1. Сервис - Android - Диспетчер устройств Android.  создайте эмулятор (например, Pixel 5, API 34) и запустите его.
2. Выберите Android Emulators - ваш эмулятор (Framework → `net10.0-android`).
3. Запустите. Первая сборка на Android может занять 5–10 минут.
